Política de Privacidad Última actualización: octubre de 2026. Este sistema es una herramienta de gestión de uso interno para un consultorio odontológico, utilizada únicamente por su personal. No está destinado al público general ni se ofrece como servicio a terceros. Qué datos se acceden a través de Google El sistema se conecta a Google Calendar exclusivamente para sincronizar los turnos del consultorio con los calendarios de los profesionales que trabajan en él. Esto permite crear, actualizar y eliminar eventos de calendario que reflejan los turnos agendados dentro del sistema. Cómo se usan esos datos La información de Google Calendar a la que se accede se utiliza únicamente para mantener sincronizados los turnos entre el sistema interno y los calendarios correspondientes. No se comparte con terceros, no se utiliza con fines publicitarios y no se vende ni se cede a ningún tercero bajo ninguna circunstancia. Dónde se almacenan los datos Los datos del sistema (incluyendo las credenciales de acceso a Google Calendar) se almacenan en una base de datos local, dentro del propio consultorio, y no se envían a servidores externos salvo la comunicación directa y necesaria con la API de Google Calendar para realizar la sincronización.
